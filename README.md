# Color System Explorer

A single-file static prototype for comparing palette, accent, and text choices across one sample layout. It is intended for social content, marketing surfaces, and editorial design exploration.

## Use

Open `index.html` in a current browser. Use the keyboard-accessible **Next** and **Previous** buttons to compare accent and text colors within each palette. The demo has no network requests, storage, API keys, or third-party assets.

Accent and text choices are filtered to a minimum 4.5:1 contrast ratio against the selected palette background. Review the finished composition in its actual context before use; this prototype does not assess every possible display condition.

This is a design-process demonstration. It is not a clinical instrument, assessment, theory demonstration, or treatment tool.
